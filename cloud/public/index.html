What does ASIP remember?

Intentions, decisions, results and recorded evidence from connected agents. With approved recording hooks, evidence can include tool inputs, outputs and source excerpts. ASIP isn’t a backup of your whole computer or every conversation.

What goes to the cloud?

You explicitly connect Beacon to your cloud account. Existing and future recorded history then syncs between your connected computers. API credentials stay on the computer where you added them.

Who controls access?

Your account keeps your memory separate from other customers. You can revoke device and API access. Cloud data is encrypted in transit and at rest; it is not end-to-end encrypted. Read the privacy details before connecting sensitive work.

Does it work with every AI chat?

Native plugins support Codex, Claude Code and Antigravity. Other compatible agents can use the ASIP API and MCP. An ordinary chat without an ASIP connection cannot recall your saved work.
