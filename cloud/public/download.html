Make your first memory.

  1. Install Beacon and sign in with Google or GitHub.
  2. Add ASIP through your agent’s native plugin manager. For Claude, choose Get plugin ZIP in Beacon and upload the ZIP through Customize → Plugins → Upload a plugin.
  3. Choose Connect cloud in Beacon and approve this computer in your browser.
  4. Ask your agent: “Use ASIP to save what we decided and what to do next for this project.” Open your cloud workspace and refresh to see the saved memory.
  5. Open a new session in the same project. Ask: “Use ASIP to recall this project. What did we decide, and what is next?”

Choose your agent.

Codex

In Beacon → Agents, choose Codex. Use Open in ChatGPT when available, or Install for the CLI. Follow the native plugin manager, open a new session, and approve the connection in Beacon. Review ASIP’s recording hooks in the agent’s hook manager.

Claude Code / Claude plugin

In Beacon → Agents, choose Get plugin ZIP. In Claude, open Customize → Plugins → Upload a plugin and select that ZIP. Keep it zipped. Approve the plugin, start a session, and confirm its connection in Beacon. Review recording hooks in your agent. Re-upload after a Beacon update to update Claude’s copy.

Antigravity

In Beacon → Agents, choose Install for Antigravity. Restart Antigravity, open a project, and approve the ASIP connection when prompted. If installation is unavailable, Beacon provides the plugin folder for the agent’s native manager.

Nothing appeared yet?

Check that your agent shows Connected in Beacon, that its recording hooks are approved, and that Beacon’s cloud connection has finished syncing. A plugin being installed is not the same as an active connection. Try the explicit save prompt above, then refresh your cloud memory.
