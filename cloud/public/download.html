From install to your next handoff.

  1. Install Beacon and sign in with Google or GitHub.
  2. Add the native ASIP plugin to Codex, Claude Code, or Antigravity.
  3. Choose Connect cloud in Beacon and approve this computer in your browser.
  4. Connect your other computers to the same workspace. Your existing and future records synchronize.

Project memory includes intent, results, session identities, and recorded evidence, including captured tool input and output. Repository working trees and full transcripts are not copied automatically. Provider credentials stay in the computer’s OS keychain.
